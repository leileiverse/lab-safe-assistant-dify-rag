## ⭐⭐⭐⭐ 三、语音问答 + 应急快速响应

### 功能描述
1. **语音输入**：事故现场无需打字，直接语音提问
2. **语音播报**：双手操作时听取安全指导
3. **应急快捷键**：一键触发"化学品泄漏""触电""着火"等预设场景

### 创新点
- 解放双手，适合应急场景
- 比打字快3-5倍
- 可用于无法使用手机的情况（戴手套、污染环境）

### 实现难度：⭐⭐
- 前端接入 Web Speech API
- 后端无需改动
- 预计开发时间：2-3天

### 代码实现
```javascript
// 前端添加语音识别
const recognition = new webkitSpeechRecognition();
recognition.lang = 'zh-CN';
recognition.continuous = false;

recognition.onresult = (event) => {
  const transcript = event.results[0][0].transcript;
  sendQuestion(transcript); // 发送语音识别的文本
};

// 语音播报答案
function speakAnswer(text) {
  const utterance = new SpeechSynthesisUtterance(text);
  utterance.lang = 'zh-CN';
  window.speechSynthesis.speak(utterance);
}
```

def generate_adaptive_quiz(user_id: str, history: list) -> list[dict]:
    """根据用户历史生成个性化题目"""
    # 分析用户薄弱点
    weak_topics = analyze_weak_points(history)
    
    # 从知识库提取相关题目
    questions = []
    for topic in weak_topics:
        kb_entries = retrieve_citations(topic, top_k=3)
        for entry in kb_entries:
